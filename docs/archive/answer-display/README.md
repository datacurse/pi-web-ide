# Archived answer display

Snapshot before switching the chat to raw output. Source files have `.txt` suffixes so they are not compiled or indexed as active code. The original paths are `src/web/<filename>`; restore them there to bring back the phase/round-based display. Supporting modules remain in the repository and history.

The active chat shows literal text (including Markdown markers), reasoning, tool arguments and results without round counts, timing bars or answer footers. Each turn has one collapsed-by-default work toggle; only the final answer stays visible. Legacy transcript preferences are retained but do not affect this raw view. Session data and activity collection are unchanged.
