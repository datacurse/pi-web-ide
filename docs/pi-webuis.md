# Pi web UI index

A discovery index of other browser interfaces for [Pi Coding Agent](https://pi.dev), excluding this repository (pi-web-ide / pwi).

**Last researched: 2026-10-04.** This is a best-effort snapshot, not a claim that every Pi UI has been found. Descriptions below summarize project/package metadata, not hands-on evaluation. Inclusion is not an endorsement, a security audit, or a claim of current compatibility.

## Scope

- Full browser workspaces and chat clients.
- Browser mirrors and remote controls for existing Pi sessions.
- Configuration, session, and observability dashboards, listed separately from full clients.
- Published variants are retained: similarly named packages can be different projects. Names alone do not establish fork ancestry.
- Excludes web-search/fetch tools, browser automation tools, themes, dashboard plugins without their own UI, chat-platform bots, and native-only apps. Related Oh My Pi projects are separate below.

## Sources and how to update

Discovery used the sibling **pkgview** package catalog, its npm metadata cache (5,250 packages tagged `pi-package`, fetched 2026-10-04), selected npm READMEs, the local PI WEB and PiChamber READMEs, and all three pages of [this GitHub repository search](https://github.com/search?q=%22pi+coding+agent%22+web&type=repositories) (277 results at research time). The search does not cover private repositories, every fork, or projects with different wording.

From the sibling catalog checkout:

```bash
node query.mjs --refresh --search web --limit 1000 --json
node query.mjs --search dashboard --limit 1000 --json
node query.mjs --search remote --limit 1000 --json
node query.mjs --show PACKAGE_NAME
```

When updating, check browser/session/mirror descriptions too, preserve npm scopes and repository owners, deduplicate component packages by project, and date the snapshot. Read each project's current installation and security documentation before trying it.

**Public source is not the same as a public server.** These UIs can expose agent tools, files, shells, and provider credentials. Publishing a repository does not imply that its running UI should be exposed to the internet without appropriate access controls.
